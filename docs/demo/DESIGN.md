# RepoMedic Demo Visual Identity

## Style Prompt

克制的深色技术审计界面。画面像一份可读的运行证据，而不是产品广告：输入、模型、工具、
测试和报告沿一条明确的数据流展开；绿色只表示真实成功，琥珀色只表示安全拒绝。

## Colors

- Background：`#08121B`
- Surface：`#122431`
- Foreground：`#E8F0F2`
- Primary flow：`#33C3B8`
- Success：`#87D68D`
- Rejected：`#F2B35D`

## Typography

- 标题：Georgia Bold；中文回退Microsoft YaHei
- 数据与工具参数：IBM Plex Mono/Cascadia Mono；中文回退Microsoft YaHei
- 数字使用等宽数字

## What NOT to Do

- 不使用炫彩渐变文字、霓虹泛光或装饰性3D。
- 不把失败涂成绿色。
- 不显示或模拟隐藏思维链。
- 不在一帧塞入完整JSON，只展示可核验的工具名称、参数摘要和结果状态。
