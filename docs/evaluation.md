# 最终评测摘要

本页只保留用于理解项目能力与限制的最终汇总；原始运行日志、逐轮审核包和中间试验材料不属于公开版本。

## RepoMedic：Complex-12

Complex-12 是 12 个受控、合成的 Python 故障夹具。每个夹具含源码、可重复失败的测试和唯一预期关键文件。它用于比较单 Agent 基线与多 Agent Flow 的证据闭环能力，并不代表真实生产仓库的总体表现。

| 指标 | 单 Agent | 多 Agent Flow |
| --- | ---: | ---: |
| Top-1 关键文件定位 | 9/12 | 9/12 |
| Verifier 确认率 | 1/12 | 8/12 |
| 平均 Token | 5,352 | 20,081 |
| 平均延迟 | 14.28 s | 40.90 s |

结论：多 Agent Flow 没有提高该夹具上的 Top-1 定位率，但在复杂跨文件问题上提高了“证据能够被失败测试确认”的比例；代价是更高的 Token 与延迟。

## RedisDoctor：版本感知 RAG

固定基准包含 17 个带来源标注的问题，比较无检索与版本感知词法 RAG。该基准规模较小，结果只说明所定义的证据约束任务，不能代表开放域 Redis 问答能力。

| 系统 | Recall@5 | MRR | 回答准确率 | 引用约束满足率 |
| --- | ---: | ---: | ---: | ---: |
| 无 RAG | 0% | 0% | 0% | 100% |
| 版本感知词法 RAG | 92.86% | 92.86% | 92.86% | 100% |

## RedisDoctor：QLoRA + RAG

使用 `Qwen/Qwen3-4B` 4-bit QLoRA。最终训练集 352 条、验证集 81 条；在 38 个源隔离问题上，将 Base + RAG 与 QLoRA + RAG 进行配对人工盲评（共 76 份答案）。

| 人工盲评指标 | Base + RAG | QLoRA + RAG |
| --- | ---: | ---: |
| 答案正确率 | 60.5% | 55.3% |
| 引用支持率 | 68.4% | 89.5% |
| 正确拒答率 | 81.6% | 76.3% |
| 幻觉率 | 18.4% | 0.0% |

自动评测中，QLoRA + RAG 的有效 JSON 率和证据约束满足率均为 97.4%，Base + RAG 均为 92.1%。答案正确率的配对差异未达到统计显著性（McNemar `p = 0.7266`）。

结论：QLoRA 在该评测中改善了结构化输出、引用支持与幻觉控制；它**没有证明**通用 Redis 问答正确率得到提升。

## 已知边界

- RedisDoctor 正式评测使用自定义版本过滤、证据筛选和引用校验链路；真实 LightRAG 检索尚未接入正式实验。
- 外部模型、GPU、完整人工审核集和 Adapter 权重不随仓库发布。
- 所有数值都依赖固定夹具或固定评测集，应连同评测范围一起解读。
